# Financial Statements Tool — downloads

This page holds the installers for the Financial Statements Tool, which prepares Balance Sheets, Statements of Profit and Loss and Notes from a trial balance: for non-corporate entities in the ICAI Guidance Note format, and for companies under Schedule III (Division I) of the Companies Act, 2013.

**Download:** [the latest version](https://github.com/uditchoithani-maker/fs-tool-releases/releases/latest)

| Your computer | File |
|---|---|
| Windows 10 or 11 (64-bit) | `Financial-Statements-Tool-Setup-….exe` |
| Mac, macOS 13 or later | `Financial-Statements-Tool-…-Mac.dmg`, where one is listed |

The other files listed with a version (`.yml`, `.blockmap`, `.zip`) are used by the tool to update itself. You do not need to download them.

## Before you install

- **A licence is needed.** Without one the tool opens and works, and your sessions are never locked, but every PDF and Excel export is marked "UNLICENSED COPY — NOT FOR ISSUE". To get a licence, send the computer code shown under **Load a licence…** to the person who gave you the tool.
- **Windows or macOS will warn you once** that it does not recognise the publisher, because the installer is not yet code-signed. The guide you were sent has the steps.
- Download the tool from this page only.

## Updates

On Windows an installed copy looks for a new version when it opens and once a day, and updates itself. Your work is saved and a backup written first. On a Mac the tool tells you when a new version is out.

## Your data

Trial balances, notes and statements are processed and kept on your own computer. No client data is sent anywhere. The tool goes online only to look for, and download, a new version of itself, which you can turn off.

## Please note

The statements, notes and workbooks the tool produces must be reviewed before they are issued or relied upon. It is an aid to preparation and does not replace professional judgement. The software is provided to licensed users only; all rights reserved.

Please do not post client data, licence files or computer codes on this page.
